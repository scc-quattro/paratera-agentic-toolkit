# 运行和故障处理

## 生命周期与存储

`make_plan` 只读查询 → `create` 保存意图并启动独立服务 → 再次验证服务 → 单次创建 → 按台账执行任务 → 下载结果 → `stop` → `wait` 确认完成。

只有台账明确登记的资源会被管理。工作目录路径参与台账指纹；不要移动目录、复制租期到其他位置，或在实例运行时删除 `.venv`、`.cache`、`.paratera`、`output/paratera/leases`。这些本机文件不进 Git，但在资源关闭前需要持久保留。并发锁只覆盖当前工作目录，不能替代账户级总预算控制。

平台“保存环境”并不等于保存全部外挂存储，也不免除存储费用。镜像、存储容量和保留费用需通过自己的控制台确认。工具不执行自动删除。

## 创建或启动失败

- 规格、报价、预算、凭据或独立服务验证失败时，不发送付费请求。
- 一旦写入 `create_attempted_at` 或 `start_attempted_at`，就可能已发送请求。超时并不说明申请失败，禁止重复申请。
- 创建回执丢失后，看门狗继续按预先核实不存在的唯一别名、可用区查询；只接受唯一匹配，并登记 UUID。出现多条匹配则拒绝操作，需由资源所有者核对。
- 状态长期处于创建中、查询不到实例、出现 `watchdog_error` 或回执结果不明时，立即人工查看平台控制台。不能为清除错误直接把台账改成 closed，也不能另开工作目录重复购买。
- 启动失败且平台仍为已保存的 Stopped 状态时，租期可结束，`closed_reason` 记录原因；这种结束不代表本次启动成功。

## 独立服务

`watchdog_unit` 保存在租期 JSON 中。用该值查看本机服务状态：

```bash
systemctl --user status 'REPLACE_WITH_WATCHDOG_UNIT.service'
```

服务日志保存在 `.cache/paratera/`，仅记录本机错误类别和安全台账；程序不输出 SDK 异常正文。请保持用户服务与控制机网络可用。独立服务只能应对 agent 退出，无法应对控制机停机或平台不可达。

若服务异常退出，可在同一原始工作目录，用原环境恢复服务：

```bash
systemctl --user restart 'REPLACE_WITH_WATCHDOG_UNIT.service'
```

不要对其他服务或其他人的租期操作。

## 关机回执不确定

关机前台账先持久化 `stop_uncertain=true`，然后发送一次 `StopServices`。收到有效异步任务编号才转为跟踪该任务。发生网络超时或响应丢失时，不盲目重发；看门狗仍观察平台状态，但无法仅凭 Stopped 证明节省模式及保存环境成功，需要资源所有者通过平台任务记录核对。

已知关机异步任务明确失败时，最多重试三次；未知结果不会自动重发。`wait --timeout` 超时仅表示未验证完成，不会取消看门狗，也不代表已停止计费。请立即核对云平台。

## 文件传输

上传只接受 `transfer/` 中的准备目录。远程路径必须是绝对路径且不含 `..`；下载保存在 `output/paratera/results/`，已有归档不会被覆盖。下载仅使用一次 SSH 会话，并把 stderr 与二进制归档分离；失败的 `.part` 文件不能作为完整结果。

远程脚本以 SSH 用户权限执行，日志会包含脚本自身的输出；脚本不得打印环境变量中的凭据。归档下载不会自动解压，解压前请检查绝对路径、`..`、符号链接和成员大小。

## 范围

本工具实现 ACKCS 容器的申请、启动、关机和任务传输。ECS 只读价格比较可用，但没有 ECS 生命周期管理、集群调度、训练、多卡或镜像构建功能。SDK 版本固定，API 结构不符时拒绝变更，需要先核对官方文档并更新测试。
